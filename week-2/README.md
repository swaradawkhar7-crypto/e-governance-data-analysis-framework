# Week 2 – Public Data Acquisition and Transformation

This week focuses on acquiring publicly available data related to digital services and e-governance and transforming raw data into analysis-ready datasets.

## Topics Covered

- Public government data sources
- API-based data acquisition
- CSV/Excel/JSON downloads
- Data cleaning
- Missing-value handling
- Duplicate removal
- Data normalization
- Data formatting
- Data validation
- Reproducible documentation

- Week 2 Task Report
- Sample government dataset
- Python transformation script
- Data dictionary
- Public data source log
